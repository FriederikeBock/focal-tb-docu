# Configuring the server

When first booting up the server, you will need to make sure that the server is now booting from the harddrive. You do that by entering the BIOS as described earlier, and first making sure, under advanced settings that the `PCH SATA` configuration is still configured to `AHCI`. If that is done you can now check in the boot menu if the SSD or Harddrive is in the list of bootdrives. If it is, place the new bootdrive on the top of the list. If not, reboot and try this step again. Press <kbd>F10</kbd> then yes to save and exit.

The server should now boot.

When entering the server, you will be presented with a terminal. You will be asked for the username(login) and password that you created earlier. When you have entered that you are now able to work on the server, congrats!!
